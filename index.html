조각의 길이

\(0 \le a < b < \tfrac{\pi}{2}\), \(h = \tfrac{b-a}{2}\)

현 \(\overline{P_aP_b}\)
\(2\,\overline{P_aM} = 2\sin h\)
그림자 \(\overline{Q_aQ_b}\)
\(\displaystyle \begin{aligned} &\tan b - \tan a \\ &= \frac{\sin(b-a)}{\cos a\cos b} = \frac{2\sin h\cos h}{\cos a\cos b}\end{aligned}\)

길이 비교

\(\displaystyle \begin{aligned} &\cos a\cos b = \tfrac{1}{2}\{\cos(b-a) + \cos(a+b)\} \le \tfrac{1}{2}(\cos 2h + 1) = \cos^2 h \le \cos h\\[16pt] &\overline{Q_aQ_b} = \frac{2\sin h\cos h}{\cos a\cos b} \ \ge\ \frac{2\sin h\cos h}{\cos h} = 2\sin h = \overline{P_aP_b} \end{aligned}\)
사용한 공식
덧셈정리, 배각공식 \(\cos 2h = 2\cos^2 h - 1\)

조임 정리에 쓰이는 \(\cos x \to 1\)

\(\displaystyle \begin{aligned} &1-\cos x = 2\sin^2\frac x2 \;\le\; 2\left(\frac x2\right)^{2}=\frac{x^2}{2}\\[16pt] &1-\frac{x^2}{2} \le \cos x \le 1 \qquad\Longrightarrow\qquad \lim_{x\to 0}\cos x=1 \end{aligned}\)
